# Portfólio — Daniel Almeida Reis

Site portfólio pessoal desenvolvido com **HTML5**, **CSS3** e **JavaScript puro**, responsivo para dispositivos móveis, com alternância entre tema escuro (padrão) e tema claro.

🔗 **Acesse o site online:** [https://DanielAlmeidaReis.github.io/DANIEL-portifolio/](https://DanielAlmeidaReis.github.io/DANIEL-portifolio/)

## Funcionalidades

- Design responsivo (*mobile-first*) com menu hambúrguer para telas menores
- Alternância de tema **Escuro / Claro** salva no `localStorage`
- Paleta em roxo, azul e branco estruturada com variáveis CSS
- Animações de revelação ao rolar a página (`IntersectionObserver`)
- Botão para copiar o endereço de e-mail com feedback visual

## Tecnologias Utilizadas

- HTML5 Semântico
- CSS3 (Flexbox, Grid, Custom Properties)
- JavaScript (Vanilla JS)
